Last updated: 2026-09-02

[1.0.0] — First public release

LicenseDesktop's first public release for Windows 10/11 (x64).
  • 100% offline license signing — master keys never leave your machine; activation codes are signed locally with RSA/JWT.
  • Tiered editions — Basic / Professional / Enterprise with per-feature gating.
  • Complete license lifecycle — issue, verify, extend, re-key, revoke, trial and expiry downgrade.
  • Online purchase — buy a license with Alipay (CNY) or overseas credit card (USD); transparent pricing.
  • 14-day full-featured trial — try everything before you buy.
  • Automatic updates — new versions arrive automatically.
  • Backups & cloud restore — automatic local backups, optional encrypted off-site copies, and restore from the cloud.
  • i18n & multi-product — Simplified Chinese / Traditional Chinese / English; issue licenses for multiple products from one Central edition.
  • Refund policy — digital goods: refund within 7 days if not activated (policy varies by currency).

Release notes for future versions will be added here on each release.
