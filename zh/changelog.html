[1.0.0] — 首个公开版本

LicenseDesktop 首个公开版本（Windows 10/11 x64）。
  • 100% 离线授权签名——主密钥永不离开你的机器，授权码在本机以 RSA/JWT 签名。
  • 三档版本分级——基础 / 专业 / 企业，按功能位门控。
  • 完整授权生命周期——签发 / 验证 / 续期 / 换机 / 吊销 / 试用 / 到期降级。
  • 双版本架构——中枢版（自有运营）+ 发行版（交付客户）。
  • 在线购买闭环——国内支付宝（CNY）+ 海外 Creem（USD）；价格由 COS pricing.json 配置驱动。
  • 试用与锁定——14 天全功能试用；到期自动锁定为只读（数据可查看 / 导出 / 备份）。
  • 自动更新——CDN 双通道 + 版本门 + 安全更新语义（patch 不限维保）。
  • 自动备份——本地滚动备份 + 可选 COS 加密异地 + 从云端恢复。
  • 多语言 / 多产品——简体中文 / 繁体中文 / English；同一中枢版签发多个软件授权。
  • 退款政策——数字化商品：7 日内未激活可退（按币种区分）。

后续版本的发布说明将在每次发布时于本页更新。
